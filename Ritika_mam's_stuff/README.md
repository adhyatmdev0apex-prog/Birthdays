# Happy Birthday, Ritika Ma'am — Cinematic Tribute Website

A warm, elegant, mobile-first birthday tribute experience crafted for **Ritika Ma'am**.

## Highlights
- **Zero-build portable architecture**: Open `index.html` directly in any browser or deploy straight to GitHub Pages / Netlify / Vercel.
- **10-stage cinematic flow**: Entry Gate (audio unlock) → Instant Preloader → Tribute Calibration Terminal → Guiding Light Opening → Dedicated Portrait Frame → 3D Appreciation Flip Cards → Polaroid Memories Gallery → Voices of Gratitude Carousel → Heartfelt Letter & Anticipation Tease → Interactive 3D Gift Box → Interactive 3-Tier Birthday Cake (Confetti + Fireworks + Birthday Song) → Nocturnal Shooting-Star Finale.
- **Hybrid Audio Engine**: Uses `assets/audio/piano.mp3` and `assets/audio/birthday.mp3` with smooth crossfading, plus a built-in Web Audio API synthesizer for gentle chimes and music-box fallback.
- **Mobile-first & Desktop responsive**: Touch swipe navigation for photos and wishes, subtle desktop 3D parallax, keyboard navigation (`←` / `→` / `Esc`), and reduced-motion accessibility.

## Personalizing Photos & Messages
- **Edit text, wishes, or letter**: Update `data/teacher.js`.
- **Add portrait photo**: Place at `assets/images/portrait.jpg`.
- **Add gallery photos**: Place at `assets/images/memories/01.jpg` through `04.jpg`.
