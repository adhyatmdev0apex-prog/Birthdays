A RECOMMENDED ARRANGEMENT

Use a GitHub App

Install it solely on the Birthdays repository. The server keeps the private key and writes only this dashboard's draft config.

Checking the connection…
Create thy GitHub App ↗View the setup notes ↓
01

Create a GitHub App with Contents: read & write and Metadata: read-only.

02

Install it upon this repository alone. No webhook or browser token is needed for local use.

03

For local use, copy .env.example to .env and add the App ID, installation ID, owner, repository, and private-key path. For Render, add a Secret File named github-app-private-key.pem and set GITHUB_APP_PRIVATE_KEY_PATH to /etc/secrets/github-app-private-key.pem. The key remains outside the connected Git repository; leave GITHUB_APP_PRIVATE_KEY unset, lest it take precedence.

Open the full GitHub App setup guide ↗

⌑ No secrets are kept in the browser. Without App credentials, this dashboard shall safely keep drafts upon this computer.
