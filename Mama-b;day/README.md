# Mama Birthday — Cinematic Mobile Website

Mobile-first, client-side birthday experience with 9 cinematic scenes:
loading, occasion, clues, reveal, Mama, messages from everyone, memory wall,
gift, celebration, and finale.

## Run locally

```bash
python -m http.server 8000
```

Open the forwarded/local URL for port 8000.

## Personalize

Edit `data/mama.js`.

Add real family photos to:
`assets/images/memories/`

Optional audio:
`assets/audio/piano.mp3`
`assets/audio/birthday-song.mp3`

The site remains functional when photos/audio are absent.
