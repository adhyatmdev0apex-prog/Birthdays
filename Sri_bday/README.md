# Happy Birthday, Sri — 21 November Birthday Surprise

A standalone cinematic birthday website for **Sri** (no dashboard).

- **Full name (`Sri Lakshmi Narasimha Rao Mulakalapalli`)** appears **only once** during the opening Universe Boot terminal scan (`Target Located: Sri Lakshmi Narasimha Rao Mulakalapalli ✓`).
- **Everywhere else (and at the end)** uses **`Sri`** only.
- Includes all 10 interactive scenes, music (`assets/audio/piano.mp3` & `assets/audio/birthday.mp3`), animations, confetti, fireworks, and the keepsake memory book.
